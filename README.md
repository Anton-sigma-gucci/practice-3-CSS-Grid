## Практична робота №3/3.1

**Тема:** Проєктування складних макетів за допомогою CSS Grid, інтеграція мультимедіа та CSS-анімацій

**Використані технології:**
- **HTML5** — створення структури сторінки та семантичних елементів.
- **CSS3** — оформлення інтерфейсу, CSS Grid, адаптивна верстка, переходи й анімації.
- **JavaScript** — реалізація логіки аудіоплеєра та взаємодії з користувачем.
